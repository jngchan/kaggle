# Missing-value experiment update

## Completed results

| Experiment | OOF AUC | Delta vs original LightGBM |
|---|---:|---:|
| Original LightGBM | 0.96386539 | 0 |
| Native v2 with aggregate missing counts | 0.96379432 | -0.00007108 |
| Median v2 | 0.96389903 | +0.00003364 |

Median v2 improved 4 of 5 folds against native v2, with mean paired gain about
0.000103. It only improved 0.000034 over the original baseline, so it is a weak
candidate rather than the main route toward 0.97.

Original LightGBM and median v2 predictions have correlation 0.99727. A 50/50 raw
probability blend reaches OOF AUC 0.96408680, improving 0.00022141 over the original
LightGBM. This is the strongest currently available OOF candidate.

The aggregate missing-count features reduced OOF and have been removed. Individual
field missing indicators remain.

## Semantic run status

The first semantic run failed before classifier training because recent pandas
versions reject float64 regressor predictions assigned into a float32 DataFrame.
The imputation code now uses float64 internally and converts generated companion
features back to float32. No valid `lightgbm_semantic_v2` OOF exists.

Run the corrected experiment as `lightgbm_semantic_v3`, then compare it with the
original `lightgbm` baseline. Keep it only if the overall and missing-field segment
gains are materially larger than the median experiment.
