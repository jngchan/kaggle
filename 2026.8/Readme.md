# Predicting Smartphone Addiction

Your Goal: Predicting smartphone addiction.

Submissions are evaluated on area under the ROC curve between the predicted probability and the observed target.

Submission File
For each id in the test set, you must predict a probability for the addicted_label variable. The file should contain a header and have the following format:

id,addicted_label
691369,0.2
691370,0.3
691371,0.1
etc.
