流程如下：

阅读数据，数据存储在data文件夹下，阅读Readme.md了解参赛需求和评测基准，然后在code中写代码，输出保存在output，但是我不在本地跑代码，你每一个版本都是一个单独的py文件，我要上传到服务器上运行，运行结果必须保存为根目录（例如2026.8）下的submission.csv文件，其他有需要能用于优化的中间结果自行设计输出。
代码设计如下：先观察数据，根据条目的名称和数据类型选择合适的缺失填补，然后根据条目名称自行构建特征工程，特征工程的构建优先构建能有实际含义的，需要避免一味按照相关性进行特征建立，可能导致错误放大。然后选择合适的模型设计训练和预测代码，务必注意数据泄露问题，其他需要注意的你可以自行补充。
然后我把代码上传到服务器上运行，我会把分数和一些输出文件下载下来给codex看，codex应当根据这些输出进行优化。但要注意，优化必须避免持续进行参数调整，这样能带来的优化很有限，进行一次到两次参数调整后需要思考更换模型结构或者更换模型进行尝试。如果我上传了别人的代码到code文件夹中，codex应当查看并思考模型架构和方法，对我当前进一步优化。
